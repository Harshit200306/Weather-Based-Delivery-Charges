# Weather-Based-Delivery-Charges

🌦️ Weather-Based Delivery Pricing System

An intelligent delivery pricing application that calculates delivery charges dynamically based on changing weather conditions and delivery distance. The system helps provide fair and efficient pricing by adjusting charges during rain, storms, extreme heat, or normal weather situations.

---

✨ Features

- Calculates delivery charges automatically
- Price changes according to weather conditions
- Distance-based fare estimation
- Real-time pricing logic for better accuracy
- User-friendly order and price interface
- Fast and smooth delivery cost prediction

---

🎯 Purpose of Project

This project was developed to solve the problem of fixed delivery charges in all situations. During bad weather, deliveries become difficult and costly. The system introduces smart pricing so charges increase or decrease fairly depending on weather and distance.

---

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Database
- Weather API

📌 Key Highlights
